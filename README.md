# Biblio

Адаптивный книжный сайт с каталогом, аккаунтами авторов и хранением данных в SQLite локально или MongoDB в облаке.

## Запуск

Нужен Python 3.9 или новее. Установите зависимости и запустите из корня проекта:

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

Откройте `http://localhost:8000`. Если `MONGODB_URI` не задан, сервер автоматически создаёт SQLite-базу в `data/biblio.sqlite3`. Если `MONGODB_URI` задан, приложение использует MongoDB; имя базы задаётся через `MONGODB_DATABASE` (по умолчанию `biblio`). Для SQLite можно изменить адрес, порт и путь к базе переменными `BIBLIO_HOST`, `PORT` и `BIBLIO_DB_PATH`.

## Развёртывание на VPS

В проект включена конфигурация Docker Compose с Caddy и SQLite для собственного VPS. Для MongoDB-варианта ниже настроено развёртывание в Render с MongoDB Atlas.

Нужен VPS с установленным Docker Engine и Docker Compose plugin. До запуска:

1. Направьте DNS-запись `A` домена на публичный IP VPS (и `AAAA`, если сервер доступен по IPv6).
2. Разрешите входящие TCP-подключения на порты `80` и `443` в firewall сервера и панели провайдера.
3. Скопируйте проект на VPS и из корня проекта выполните:

```bash
cp .env.example .env
```

Укажите в `.env` свой домен вместо `biblio.example.com`, затем запустите:

```bash
docker compose up -d --build
docker compose ps
```

Сайт будет доступен по `https://ваш-домен`. SQLite-база хранится в постоянном Docker volume `biblio-data` и сохраняется при пересборке контейнера. Для резервного копирования регулярно копируйте базу из этого volume; не удаляйте volume при обновлении проекта. Локальные настройки, избранное и прогресс чтения остаются в браузере каждого читателя.

Обновление после загрузки новых файлов проекта:

```bash
docker compose up -d --build
```

Для временной остановки:

```bash
docker compose down
```

Команда `docker compose down -v` удаляет постоянные тома, включая базу и сертификаты, поэтому для обычного обновления её использовать нельзя.

## Развёртывание на Render

В корне проекта есть `render.yaml` для Render Blueprint. Приложение использует MongoDB Atlas; сам Render не предоставляет управляемую MongoDB.

1. Создайте кластер MongoDB Atlas и добавьте сетевое правило, разрешающее подключения с Render. Для более строгой настройки используйте список исходящих IP-адресов вашего Render-сервиса вместо разрешения `0.0.0.0/0`.
2. Создайте в Atlas пользователя базы данных и скопируйте URI подключения. Не добавляйте его в репозиторий.
3. Отправьте файлы проекта в GitHub-репозиторий.
4. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите создание сервиса из `render.yaml`.
5. В настройках созданного сервиса добавьте `MONGODB_URI` со значением из Atlas. Это секретная переменная; задавайте её только в Render Dashboard. `MONGODB_DATABASE` уже установлена в `biblio`.
6. После завершения деплоя откройте выданный Render адрес `*.onrender.com`; HTTPS на нём настраивается автоматически.

Render может использовать бесплатный web service, но ограничения и условия бесплатного плана определяются Render. Пользователи, книги, главы, оценки, сессии и подписки будут сохраняться в Atlas. Избранное, настройки и прогресс чтения по-прежнему хранятся отдельно в браузере читателя. Одна и та же MongoDB поддерживает несколько экземпляров приложения.

Если у вас уже есть данные в `data/biblio.sqlite3`, они не переносятся автоматически. Сохраните резервную копию SQLite перед переключением; для переноса данных потребуется отдельная миграция.

## Страницы сайта

- `/` — главная с подборками, жанрами и книжным клубом.
- `/catalog` — поиск, фильтры и каталог книг.
- `/authors` — авторы и их книги.
- `/club` — книжный клуб и подписка на новости.
- `/library` — читательская полка с текущим прогрессом, прочитанными книгами и избранным; авторские черновики доступны после входа.
- `/settings` — настройки сайта, чтения и аккаунта.

Страницы открываются напрямую по адресу и доступны из общей навигации.

## Возможности

- Поиск по названиям книг и авторам.
- Фильтры каталога по жанру, возрасту, языку, объёму, тегам и рейтингу.
- Автоподсказки, история запросов, сортировка и постраничная навигация.
- Страницы книг с описанием, похожими произведениями и оценками читателей.
- Бесплатное онлайн-чтение книг, созданных авторами, и встроенных рассказов.
- Переключение глав и сохранение места чтения.
- Личная полка: список читаемых и прочитанных книг, прогресс по главам и избранное на этом устройстве.
- Отдельные настройки сайта и чтения: темы, шрифт, размер, интервал и ширина текста.
- Предпросмотр настроек чтения, избранное и уведомительные предпочтения сохраняются в браузере.
- Регистрация, вход, выход и настройки профиля.
- Профиль аккаунта, смена пароля и повторно используемое подтверждение действий.
- Карточки книг и авторов, список глав и скачивание текста книги в TXT.
- Создание и редактирование книг с описанием и главами.
- Редактор глав с автосохранением черновика на этом устройстве.
- Сохранение черновика, доступного только владельцу, или публикация в общем каталоге.
- Удаление своих книг и чтение опубликованных книг.
- Адаптивное меню и сохранение подписки на новости.

Пароли хранятся в виде хешей. Сессии сохраняются в выбранной базе данных, а токены в браузере защищены флагами `HttpOnly` и `SameSite`.
